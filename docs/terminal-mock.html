1 · First command of the day (cold engine)

keeper@dev-server: ~
$ bmdctl preview mp1
Studio ATEM  1 M/E Constellation HD · 1080p25 · connected 330 ms
  preview   Ca2 → MP1                                      32 ms

$ bmdctl program 2
Studio ATEM
  program   lkkk → Ca2                                     21 ms

$ bmdctl cut
Studio ATEM
  cut       MP1 on program · Ca2 on preview               sent

$ bmdctl preview mp1
Studio ATEM
  preview   MP1                                       already

Switcher name once as a header, bold. Results indented under it. Only the value now on the bus is coloured. The word "confirmed" is never printed; it's the default. Exceptions (sent, already, rejected) are one dim word where the timing goes. Connection details appear once, on the line where the connection happened, then never again.

       bmdctl doctor checks the network

$ bmdctl video mode 1080p50
error  video mode resyncs every output
       add --yes to do it

No "bmdctl atem program:" prefix; the user just typed it. One red word, the message, one dim hint.

Studio ATEM  open.cue · 5 lines
  1  preview      Ca2 → MP1                                18 ms
  2  transition   mix 1:00                                 22 ms
  3  auto         MP1 on program · Ca2 on preview           sent
  4  key 1 fill   Cam_1                                    20 ms
  5  key 1        on air                                   24 ms
  done · 5 ok

Rules behind all of it: nothing wider than 72 columns; context (which switcher) stated once per invocation as a header, never per line; verbs in a fixed 10-char column so eyes land on the same spot; only the current bus value coloured; secondary information dim; timings right-aligned; empty and repeated rows collapsed.
